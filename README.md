# XL125R Chassis Bench

Whole-bike geometry and Pro-Link linkage calculator for Joel's 1982 Honda XL125R rally build.

Open https://blevo66.github.io/chassis-bench in Safari on the iPhone, tap Share, then Add to Home Screen. It works offline and keeps your numbers on the phone; use Back up to save them to a file.

Swingarm & linkage calculator, a generic measuring guide for a swingarm and linkage: https://blevo66.github.io/chassis-bench/arm.html. Send that link to whoever is measuring. Their "Send to Joel" message includes a link that opens the bench with the numbers waiting in measuring mode, ready to check and apply.

Rocker & dogbone designer: the second view of the bench (the Rocker & dogbone button under the header, or https://blevo66.github.io/chassis-bench/#rocker). Put in the swingarm, the frame's shock top and dogbone mounts, the shock and the angle it runs at, plus the travel and rising rate you want, and it designs the rocker and dogbone. "Put it on the bike and show me" sends the design to the whole bike (padlocked numbers there are left alone), which now has just the one set-up, and it makes STL files for a full-size PLA mock-up. Back up and Restore cover both views. The old rocker.html address forwards to it. Its code is the second script in index.html, kept in its own scope; the merge script that first built it from the stand-alone page is in the project's chassis/rocker folder.
