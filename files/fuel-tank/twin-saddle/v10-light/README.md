# v10-light (17 Nov): same v9 style, slimmer and shallower so it looks and is lighter
Built with `ZBF=280 YOF=185 python3 ../build9.py .` (same parts list and fold rules as v9).

| | v9 | v10-light |
|---|---|---|
| Capacity (calculated, gross) | 14.0 L | 10.2 L |
| Pod bottoms above pivot | 178 | 296 (about 120 mm more air under them) |
| Width across pods | 376 | 346 |
| Shell, 1.2 mm steel (calculated) | 5.1 kg | 3.8 kg |
| Shell, 1.0 mm steel (calculated) | 4.3 kg | 3.2 kg |
| Shell, 1.5 mm 5052 alu (calculated, needs TIG) | 2.2 kg | 1.6 kg |
| Fittings: 2 caps, tap, crossover, baffles, mount cups, weld (GUESS) | ~0.7 kg | ~0.7 kg |
| Fuel when full (0.74 kg/L) | 10.4 kg | 7.5 kg |
Shell weights are flat-pattern area x thickness x density. Longest fold 162 mm.
