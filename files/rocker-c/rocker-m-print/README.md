# Rocker M mock-up print set (2026-11-06)

Frame rocker on the XL lower mount (30 back / 65 down from the swingarm pivot), short dogbone to the CRF250 arm lug (CAD position). Full droop is designed at 22 deg. XR250R shock 380/95 with the stock spring.

- Shock bottom eye at full droop: about 194 mm behind and 5 mm above the swingarm pivot (about 194 mm in a straight line).
- XR 380/95: about 200 mm wheel travel, leverage 2.12 -> 2.06 (gentle 3% rise).
- Custom 380/120 later: about 251 mm with the same rocker.
- Rocker: P-S 178.7, P-D 142.0, S-D 177.3, 66 deg. Dogbone 49.9 centres.
