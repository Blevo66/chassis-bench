# XL125R dash: demo mode (Arduino IDE)

Fake ride on a loop so you can see the dash move: needle sweep at power-on, rev up through the gears, shift light, cruise with high beam, overtake indicator, brake, stop. Swipe left/right (or tap) for RIDE / TRIP / SYSTEM pages. If the GPS is wired (TX -> GPIO17, RX -> GPIO18, 9600 baud) and has a fix, speed comes from the GPS.

## Files (all three go in one folder called `xl-dash-demo`)
- `xl-dash-demo.ino`: tiny, just calls the code
- `dash_demo.h`: all the code; settings at the top
- `fonts.h`: smooth (anti-aliased) fonts, generated by `tools/make_fonts.py` from Inter (SIL OFL)

## Arduino IDE settings
Board ESP32S3 Dev Module (esp32 core **3.2.0**), USB CDC On Boot Enabled, Flash 16MB, **PSRAM: OPI PSRAM**, any 16M partition. Libraries: GFX Library for Arduino 1.5.5, TCA9554 0.1.2.

## How it stays smooth
- Needle and speed ease to new values (critically damped, ~100 ms).
- Only what changed is redrawn and sent (dirty rectangles), from a PSRAM frame buffer.
- Faded ghost needles behind the real one (fake motion blur).
- Anti-aliased needle, dial, icons and text (own blending, not the library's).

## Status
- Compiles and runs on a PC with stand-in Arduino/GFX headers (`tools/host-preview`), which also made the pictures in `previews/`. **Not yet compiled for the ESP32 itself** (no ESP32 toolchain reachable from the build server).
- Touch mapping (`TOUCH_*` in `dash_demo.h`) is a guess. The SYSTEM page shows where it thinks you touched.
