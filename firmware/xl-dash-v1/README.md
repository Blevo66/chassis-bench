# XL125R dash v1 (Arduino IDE)

The proper dash firmware, on the drawing engine from `xl-dash-demo`. Replaces the PlatformIO `firmware/xl-dash` (WiFi page and Bluetooth ignition battery not brought across yet).

## Files: all in one folder called `xl-dash-v1`
- `xl-dash-v1.ino`: start-up only
- `config.h`: **settings and pin map, start here** (`DEMO_MODE` 0 = real, 1 = fake ride)
- `dash.h`: the code
- `fonts.h`: smooth fonts (generated by `tools/make_fonts.py`)

Arduino IDE: ESP32S3 Dev Module, esp32 core **3.2.0**, USB CDC On Boot Enabled, Flash 16MB, **PSRAM OPI PSRAM**. Libraries: GFX Library for Arduino 1.5.5, TCA9554 0.1.2.

## What works (real mode)
| Input | Does |
| --- | --- |
| IND L / IND R (PA0 / PA1) | tap on/cancel, hold 0.7 s hazards; arrows flash in sync with OUT1/OUT2 |
| HORN (PA2) | OUT5 + HORN light while pressed |
| LIGHTS (PA3) | headlight off at power-up; tap with headlight off = flash high beam (0.4 s, `PASS_FLASH_MS`); tap with headlight on = high/low; hold 3 s = headlight on (low) / off. DRL (OUT7) always on: full with headlight off, 20% with it on. (beam icon: blue high, green low, grey off) |
| MODE (PA4) | tap = nothing (spare), hold = next page; on TRIP page keep holding 3 s = reset trip A |
| GPS (IO17/18, 9600) | speed (0 below 1.5 mph), odometer + trips saved to flash every 0.1 mi, UK clock (BST auto) |
| RPM (IO21) | needle, once the pickup is fitted (`SPARKS_PER_REV` is a guess) |
| Brake (IO48) | BRAKE light |
| AXP2101 | dash LiPo % + charging (register map from XPowersLib, unchecked) |

Pages: RIDE, TRIP, SYSTEM, **TEST** (live buttons, button-chip address, all 8 outputs, brake, RPM, GPS).
The button chip is searched for at 0x21-0x27 (0x20 is the screen board's own chip), and again every 2 s if unplugged.

## Status
Compiles and runs on a PC with stand-in headers (`tools/host-preview`, pictures in `previews/`). The ESP32 build is untested; the demo built from the same engine has run on the real board.

## Outputs: dumb box with a PCA9685 (default)
`OUTPUTS_VIA_PCA9685 1` in `config.h`: the 8 outputs go through a PCA9685 "16-channel PWM
servo driver" breakout in the dumb box (address 0x40, pads untouched), on the same I2C wires as
the left controller. Channels 0..7 -> MOSFET board IN1..IN8 (OUT1 IND L, 2 IND R, 3 LOW,
4 HIGH, 5 HORN, 6 USB, 7 DRL, 8 TAIL), its GND to GND, its VCC to 5V. Leave the servo V+ empty.

8-pin link screen <-> box: 1+8 5V, 2+7 GND, 3 SDA (IO8), 4 SCL (IO7), 5 RPM (IO21), 6 brake (IO48).

Test page: **BTN** (button chip) and **OUT** (output chip) go green when found, red when not.
Set `OUTPUTS_VIA_PCA9685 0` to drive the MOSFET board from GPIO `PIN_OUT` instead (unchecked pins).
